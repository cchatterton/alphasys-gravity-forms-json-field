Populate a Gravity Forms JSON hidden field from submitted form values.

== Description ==

Populate a Gravity Forms JSON hidden field from submitted form values. This is a beta release of the installed implementation. The codebase standards migration is planned for a later release.

== Installation ==

Install through the AlphaSys update controller or upload the release ZIP in WordPress. Activate the plugin after installation. Gravity Forms is required for its features.
